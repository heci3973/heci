# my-first-repo

第一个 GitHub 仓库，用来跑通 Git 的完整流程（本地提交 → 远程推送）。

## 现在有什么

- `README.md`：本文件
- `.gitignore`：忽略 Windows、编辑器、Office 临时文件等常见杂物

## 常用命令

```bash
git status          # 看当前改动
git add .           # 把改动加入暂存区
git commit -m "说明"  # 提交
git push            # 推送到 GitHub
```
